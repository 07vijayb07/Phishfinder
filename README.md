# PhishFinder – Real-Time Phishing Detection Plugin

This browser extension detects phishing websites using machine learning and URL-based analysis techniques.

![License](https://img.shields.io/badge/license-MIT-green)
![Status](https://img.shields.io/badge/status-beta-blue)

Dataset: [UCI Repository](https://archive.ics.uci.edu/ml/index.php)

Technique: Random Forest Classifier
